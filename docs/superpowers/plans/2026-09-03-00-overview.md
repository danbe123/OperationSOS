# Operation SOS Implementation Overview

> **For agentic workers:** This overview locks the file structure and the interface contracts every sub-plan depends on. Read it before any sub-plan. Sub-plans: `01-backend-and-install`, `02-frontend`, `03-content`, `04-maps-pipeline`, `05-ai`. Each sub-plan is executed with superpowers:subagent-driven-development.

**Goal:** Build Operation SOS, an offline UK survival knowledge box for a Raspberry Pi 5 with a touchscreen and WiFi hotspot, per the spec.

**Architecture:** systemd services (Caddy, kiwix-serve, a FastAPI backend, optional llama.cpp) on Raspberry Pi OS Lite; a React single-page app served statically over plain HTTP and used both in a kiosk browser on the Pi's screen and on phones over the hotspot; content is ZIM files, PMTiles maps, PDFs and authored Markdown playbooks described by a JSON manifest.

**Tech Stack:** Python 3.12+, FastAPI, uvicorn, httpx, SQLite with FTS5, markdown-it-py, python-frontmatter, pydantic, jsonschema; React 19, TypeScript, Vite, react-router 7, MapLibre GL JS, pmtiles, proj4, simple-keyboard, qrcode, pdfjs-dist, epubjs; Caddy 2, kiwix-tools 3.8, llama.cpp; pytest, respx, Vitest, Testing Library, Playwright.

**Spec:** `docs/superpowers/specs/2026-09-03-operation-sos-design.md` (revised 2026-09-03 after review; the spec wins over anything older).

## Global Constraints

- Python 3.12 or newer (the Pi runs 3.13); Node 22 or newer; pnpm for the frontend.
- No Docker anywhere. No runtime dependency on the internet. No service worker (plain HTTP is not a secure context). No CDN references in any HTML, CSS or JS; fonts, icons, map styles, sprites, glyphs and PDF.js are bundled.
- kiwix-serve is started with `--address all --nosearchbar --nolibrarybutton --blockexternal`.
- llama-server binds 127.0.0.1:8081 and is never proxied by Caddy; sos-api is its only client.
- Manifest invariant: every `zim` item's `dest` is `zim/<id>.zim`, so the Kiwix book name in URLs equals the manifest item id.
- All authored content is British English. Emergency numbers are 999, 111, 105, 0345 988 1188 (Floodline). Drug names are UK names.
- Never name the product "NOMAD". The product name is "Operation SOS"; the short name in UI copy is "SOS".
- Kiosk layouts are designed and tested at 853x480 CSS px; phone layouts at 360 to 430px wide. Touch targets at least 48px.
- Every commit passes `make test`.
- Licence is informational (`licence` field) and never gates behaviour.
- Dev profile: `SOS_DEV=1` runs the whole stack on a PC without hotspot, kiosk, mount units or sysfs.

### Manifest item (manifest/schema.json)

```json
{
  "id": "wikipedia_en_all_maxi",
  "title": "Wikipedia (English, with images)",
  "kind": "zim",
  "tier": "core",
  "category": "reference",
  "scenarios": [],
  "source": { "type": "kiwix", "name": "wikipedia_en_all_maxi" },
  "dest": "zim/wikipedia_en_all_maxi.zim",
  "size_bytes": 123980647016,
  "as_at": "2026-02",
  "licence": "CC BY-SA 4.0",
  "priority": 10,
  "reader_home": "A/Main_Page",
  "description": "One sentence shown in the library",
  "search_weight": 1.0,
  "suggest": true,
  "overlay": null
}
```

- `kind`: `zim | pmtiles | geojson | pdf | epub | dir | model | mwm | apk | style | glyphs | sprites | places`
- `tier`: `core | extended`
- `category`: `playbooks | uk-official | medical | survival | reference | practical | maps | education | books | media | ai`
- `source.type`: `kiwix` (`name`), `url` (`url`, optional `sha256`, optional `mirrors[]`), `build` (`tool`, `artifact`)
- `dest` is relative to the tier root. For `zim` items it must equal `zim/<id>.zim`.
- `search_weight` default 1.0; `suggest` default false; `reader_home` optional; `as_at` is `YYYY-MM-DD` or `YYYY-MM`.
- `overlay` (overlays.json only): `{ "id", "kind": "geojson" | "pmtiles" | "style-layer", "layer_id"?, "default_on": bool, "coverage": string[], "color": "#hex", "icon": string | null }`; `scenarios_on` is derived at index time from playbook front matter.

Python: `sos.manifest.Item` (pydantic model with exactly these fields), `load_manifests(dir) -> list[Item]`, `validate_manifests(dir) -> list[str]` (errors, empty if valid).

### Database (api/sos/db.py)

```sql
CREATE TABLE library_items (
  id TEXT PRIMARY KEY, title, kind, tier, category, scenarios_json, dest, size_bytes INTEGER, as_at, licence,
  priority INTEGER, reader_home, description, search_weight REAL NOT NULL DEFAULT 1.0, suggest INTEGER NOT NULL DEFAULT 0,
  overlay_json, available INTEGER NOT NULL DEFAULT 0, local_path, fts INTEGER NOT NULL DEFAULT 0,
  resolved_name, resolved_size INTEGER, resolved_as_at);
CREATE VIRTUAL TABLE fts_docs USING fts5(
  title, body, doc_id UNINDEXED, kind UNINDEXED, category UNINDEXED, scenarios UNINDEXED, page UNINDEXED, url UNINDEXED,
  tokenize='porter unicode61 remove_diacritics 2');
CREATE VIRTUAL TABLE fts_places USING fts5(
  name, kind UNINDEXED, lat UNINDEXED, lon UNINDEXED, region UNINDEXED, postcode UNINDEXED,
  tokenize='unicode61 remove_diacritics 2', prefix='2 3 4');
CREATE TABLE checklist_state (playbook TEXT, item_id TEXT, checked INTEGER NOT NULL, updated_at TEXT, PRIMARY KEY (playbook, item_id));
CREATE TABLE notes (id INTEGER PRIMARY KEY AUTOINCREMENT, kind TEXT NOT NULL DEFAULT 'note', title TEXT, body TEXT, lat REAL, lon REAL, updated_at TEXT);
CREATE TABLE settings (key TEXT PRIMARY KEY, value TEXT);
CREATE TABLE search_cache (q TEXT PRIMARY KEY, results_json TEXT, created_at TEXT);
CREATE TABLE places_meta (key TEXT PRIMARY KEY, value TEXT);   -- source file mtime/size so import runs only on change
```

`sos.db.connect(path) -> sqlite3.Connection` (row factory `sqlite3.Row`, WAL), `sos.db.init_schema(conn)` idempotent. `fts_docs` ranking uses `bm25(fts_docs, 5.0, 1.0)`.

### Authored content format (playbooks/)

Scenario front matter: `id, title, icon, order, summary, modules[], overlays[], reviewed (date or null), sources[] ({title, doc?, kiwix?, url?, as_at?})`. Module, card and page front matter: `id, title, icon, order, summary` (modules also `sources`; pages also `category: 'comms' | 'reference' | 'plan' | 'about'`). Scenario bodies contain exactly, in order: `## Right now`, `## First 72 hours`, `## First month`, `## Long term`, `## UK specifics`, `## Checklist`, `## Go deeper`. `## Checklist` contains only `- [ ] text` or `- [ ] text {#id}` lines; item id = explicit id or `slugify(text)[:60]`. `{{module:<slug>}}` on its own line includes a declared module.

Python API in `sos.content`: `parse_document(path) -> Document` (`id, title, icon, order, summary, kind, modules, overlays, reviewed, sources, sections: list[(id, title, markdown)], checklist: list[(item_id, text)], category`); `render_markdown(md, link_resolver) -> str`; `render_document(doc, resolver, modules: dict[str, Document]) -> RenderedDocument`; `validate_tree(playbooks_dir, manifest_items, overlay_ids) -> list[str]`.
