> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove everything a household has to type in before the box is useful (the register, neighbours, Stock, readiness, per-person tasks), leaving one number, "how many people", for the kits.

**Architecture:** Deletion first, then two small additions: a `people` setting with its own endpoints and a stepper on the Kit overview, and a "Start here" block on Now in peacetime. The removal map at `docs/superpowers/plans/2026-09-07-no-setup-context.md` lists every file, function, rule and test involved with line numbers as of `44efcfb`; each task below names what it owns and points at the map for the detail.

**Tech Stack:** Python 3.12 + FastAPI + SQLite (api/), React 19 + react-router 7 + Vite + vitest (web/), YAML rules (playbooks/rules).

**Spec:** `docs/superpowers/specs/2026-09-07-no-setup-design.md`.
