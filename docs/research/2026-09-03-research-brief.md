

# nomad_facts

## What Project NOMAD verifiably is (state at v1.34.1, 2 Sep 2026)

**Identity.** Project NOMAD, by Chris Sherwood / Crosstalk Solutions, LLC (Springfield, Oregon; GitHub @chriscrosstalk, YouTube @CrosstalkSolutions). Repo github.com/Crosstalk-Solutions/project-nomad created 24 Jun 2025, v1.0.0 11 Jul 2025, now 36,481 stars / 3,639 forks. Backronym was "Node for Offline **Media**, Archives, and Data" through v1.33; the current About page says it started as "Node for Offline **Maps**, Archives, and Data" and is retired ("these days we just call it NOMAD"). Licence Apache-2.0 since v1.28.0 (5 Mar 2026) — a relicensing from MIT. Volunteer-run, no paid tier, no hardware sold (affiliate links on the hardware page, Ko-fi), "ZERO built-in telemetry" (README). Virality is a **2026** event: launch video 12 Mar 2026, #1 GitHub trending and HN front page (610 pts, 222 comments) 21 Mar 2026, ZDNet 30 Mar.

**Correction to the template premise.** NOMAD is not a Raspberry Pi / hotspot / captive-portal appliance. It is an x86-64-only Docker stack installed with `curl … | sudo bash` on Ubuntu 26.04 (recommended) / 24.04 / Debian 12, served on port 8080 to whatever LAN already exists. No AP mode, captive portal, mDNS, QR onboarding or authentication exists in installer, compose or code. The official Guides page shows a GL.iNet Beryl 7 travel router as the way to make it a hotspot.

**Distribution.** One script, install/install_nomad.sh: checks /etc/debian_version; on non-x86_64 prints a warning citing PR #419, sleeps 10 s and continues (does not abort); installs Docker via get.docker.com; NVIDIA Container Toolkit if lspci/nvidia-smi finds a GPU, or writes AMD gfx codename to storage/.nomad-amd-gfx (ROCm configured when the AI app installs); creates /opt/project-nomad; downloads install/management_compose.yaml; generates APP_KEY + MySQL passwords; injects URL=http://<lan-ip>:8080; runs `docker compose -p project-nomad`. Auto-start is only `restart: unless-stopped` (no systemd unit). No ISO or disk image; GitHub releases carry no assets; the software ships solely as container images ghcr.io/crosstalk-solutions/project-nomad (+ -sidecar-updater, -disk-collector), all **amd64-only single-arch manifests** because CI has no `platforms:`. Kiwix pre-install always downloads a 4.5 MB seed ZIM (install/wikipedia_en_100_mini_2026-01.zim) from the repo because kiwix-serve needs one ZIM to start — it is required, not a test file.

**Official hardware guidance (projectnomad.us/hardware).** Minimum (Command Center only): 2 GHz dual-core, 4 GB RAM, 5 GB disk. AI: Ryzen 7/i7, 32 GB, RTX 3060+, 250 GB+ SSD. Tiers: Budget $150–300 (used OptiPlex Micro / ThinkCentre Tiny / EliteDesk Mini, 8th-gen i5/i7 or Ryzen 5, 16–32 GB, iGPU; 1–3B models 5–20 tok/s; NOMAD Score 150–450); Recommended $500–800 (Minisforum/Beelink, Ryzen 7/9 8845HS/7840HS/AI 9 HX 370, 32 GB DDR5, 1 TB NVMe, Radeon 780M/890M: 8B at 12–17 tok/s, 1–3B ~50 tok/s; score 850–1,100); Power $1,000+ (RTX 3060 12 GB+ ~65 tok/s, RTX 3090 ~150 tok/s; score 1,100–3,000). Tested: MS-02 Ultra (Core Ultra 9 285HX + RTX 5060, 2,003, 84.2 tok/s), AI X1 Pro (1,080, 15.8), UM890 Pro (989, 12.3). Reference build is "Ryzen 9 PRO 8945HS with Radeon 780M" = score 1,000 — the "Minisforum MS01" attribution in secondary sources contradicts the primary page. Power: "A mini PC draws 15–65 W"; the "200–400 W GPU desktops" figure is not official (EmergencyKitLab says 150–300 W). On Pi: the page says NOMAD "is designed for more capable hardware to support local AI" and points to Internet-in-a-Box; maintainer in issue #816 (May 2026): "x86_64 only today … no committed timeline for arm64".

**Architecture.** management_compose.yaml: admin (AdonisJS 6.19 / Node 22-slim / Lucid / BullMQ on Redis / Transmit SSE; React 19 + Inertia + Vite) on 8080, mounting /opt/project-nomad/storage and /var/run/docker.sock (Docker-outside-of-Docker); dozzle v10.0 on 9999; mysql:8.0 and redis:7-alpine internal-only since v1.30; updater + disk-collector sidecars (alpine:3.20). Command Center spawns workload containers via the host socket. Storage: /opt/project-nomad/storage/{zim, maps/pmtiles, books, media, kb_uploads, logs, models, per-app dirs} — there is **no manifests/ directory**; manifests cache in MySQL table collection_manifests. Auto-update: core (same-major, 72 h cool-off, 02:00–05:00 window, disables after 3 failures), apps opt-in, content refresh with byte caps (v1.33). OpenAPI/Scalar docs (v1.34).

**Security.** README: "it includes no authentication" by design; admin-lock request #1238 closed not-planned Aug 2026. Caddy basic-auth guide hosted at projectnomad.us/install/caddy, labelled community-supported. Supply Depot defaults are universal: File Browser admin/nomad, Calibre-Web admin/admin123, Stirling PDF login disabled — docs say "It's the same default on every NOMAD". MySQL passwords are randomised per install, so per-unit secrets are a solved pattern in the codebase.

**Apps and ports.** Six core tools, none installed by default: AI Assistant (ollama/ollama:0.24.0 on 11434 + qdrant v1.16 on 6333), Information Library (ghcr.io/kiwix/kiwix-serve:3.8.1 on 8090, `--library /data/kiwix-library.xml --monitorLibrary --address=all`), Education Platform (Kolibri Gen 2 learningequality/kolibri:0.19.4 on 8310/8311; legacy treehouses 0.12.8 on 8300 deprecated), Maps (inside Command Center on 8080, PMTiles + MapLibre), Data Tools (CyberChef 10.24.0 on 8100), Notes (FlatNotes v5.5.4 on 8200). Since v1.34 the Easy Setup wizard offers only Library, Education, AI (Maps in step 2); Notes/Data Tools install from Supply Depot. Supply Depot (v1.33): Stirling PDF 2.13.1, File Browser, Calibre-Web 0.6.26, IT Tools, Excalidraw, Homebox, Vaultwarden, Jellyfin 10.11.11, Meshtastic Web, MeshCore Web, plus arbitrary Docker images. No chat, no mesh bridge, no Meshtastic↔LLM integration.

**LLM stack.** Ollama + Qdrant RAG. Fallback models (admin/constants/ollama.ts): llama3.1:8b-text-q4_1 (5.1 GB), deepseek-r1:1.5b (1.1 GB), llama3.2:1b-text-q2_K (581 MB); query-rewrite qwen2.5:3b; embeddings nomic-embed-text:v1.5. RAG context by model size: ≤3B 2 results/1,000 tokens; ≤8B 4/2,500; larger 5/uncapped. Knowledge Base ingests PDF/TXT/EPUB/DOCX/images (≤5×100 MB), guardrails at 50 GB, 10% free disk or >6 h embed time, Manual ingest default; ZIMs embeddable in 50-article batches (RFC #883: a 10 GB ZIM can need 1–100 GB of Qdrant). v1.31 remote OpenAI-compatible hosts; v1.34 nomad.md custom instructions, per-model thinking toggle. GPU: NVIDIA ("100+ tok/s" vs CPU "10–15"); AMD ROCm re-enabled v1.32, iGPU fixes v1.34, yet the docs GPU page still says AMD unsupported. Hallucination: docs pages carry no warning; website FAQ says "Local AI can be wrong … It's a tool, not an oracle"; RAG prompt says "Do not fabricate specifics". The HN hallucination report (Schlagbohrer) concerned the commenter's own Qwen2.5-27B setup, not NOMAD.

**Content sourcing — nothing bundled.** CollectionManifestService fetches four manifests at runtime from the **`main` branch** on GitHub raw (collections/kiwix-categories.json, wikipedia.json, maps.json, creator-packs.json), cached in MySQL. ZIM URLs point at download.kiwix.org, but resolveZimDownload() swaps in a newer version from the Kiwix OPDS catalogue when one exists. The in-app catalogue browser hard-codes `lang:'eng'` (PRs #1299/#1298 to lift this opened 31 Aug 2026, still open). v1.32 custom library sources seeded with Debian CDN, Your.org, Dotsrc, MirrorService (UK). Sideload = drop .zim in storage/zim/ + "Rescan Library" (v1.33), or upload ≤20 GB. Upstream filename renames break tiers (PR #1187). Kolibri channels need internet (Studio) or a local drive/peer.

**Wikipedia — refuted claim corrected.** Six English-only options (spec 2026-08-02): none; top_mini 331 MB; top_nopic 2,239 MB; all_mini 12,531 MB; all_nopic 52,690 MB; all_maxi_2026-02 123,980 MB (exactly 123,980,647,016 bytes = 115.5 GiB). The "reviewers measured 99.6 GB" claim is **false**: 99.6 GiB was the app's listed size for the older 2024-01 file. In-app FAQ still says "~95 GB" (stale); website says ~125 GB. One Wikipedia selection at a time. Other-language Wikipedias are **not** reachable via the catalogue browser, only by sideload / mirror browser / uploader.

**Curated catalogue (collections/kiwix-categories.json, spec 2026-03-15).** 6 categories × 3 cumulative tiers, 62 entries (61 unique; openfda-drug-labels is a `dataset` from api.fda.gov, not a ZIM), ~87 GB at Comprehensive. Medicine Essential: zimgit-medicine 67 MB, **nhs.uk_en_medicines 16 MB**, FAS military medicine 78 MB, CDC 170 MB; Standard: MedlinePlus 1.8 GB, openFDA labels 1.7 GB; Comprehensive: WikiMed 2 GB, LibreTexts med 1.1 GB, librepathology 76 MB. Survival: zimgit water 20 MB / food-prep 97 MB / knots 27 MB, Canadian Prepper video packs (1,340 / 975 / 2,890 / 2,160 MB), ready.gov 2,429 MB, outdoors.SE 142 MB, ham.SE 75 MB, urban-prepper 2,240 MB, post-disaster 644 MB, 100r.co 172 MB, Gutenberg LCC-U 1.2 GB, cd3wd 581 MB. Education: wikibooks 3.1/5.4 GB, TED-Ed 5.61 GB, wikiversity 2.37 GB, LibreTexts subjects, TED conference 16.5 GB. DIY: woodworking/mechanics/diy SE, iFixit 3.38 GB. Agriculture: foss/based cooking, gardening/cooking SE, lrnselfreliance 3.79 GB, Gutenberg LCC-S 4.3 GB. Computing: freecodecamp, devdocs, arduino/raspberrypi/electronics/robotics SE. Survival tier was 89% YouTube-channel video until PR #1187 (2 Aug 2026, text share now 36%). Absent: wikiHow (Kiwix no longer distributes it), full Gutenberg, Stack Overflow, Survivor Library (252 GB, excluded on size).

**Maps.** collections/maps.json (spec 2026-02-11): 50 US-state PMTiles (dated 2025-12) in 9 census divisions (1.2–3.2 GB each), stored via **Git LFS** in Crosstalk-Solutions/project-nomad-maps (MIT scripts, ODbL data; e.g. alabama 236 MB, texas 903 MB, global-min 176 MB). Zero non-US entries. Since v1.32 map_service.ts runs `pmtiles extract` against the latest Protomaps build over HTTP range requests, zoom 0–15, using Natural Earth country polygons grouped by continent — UK and Ireland are selectable, but extraction needs internet. Custom PMTiles URL import exists. Viewer: MapLibre GL, POI/address search, pins (v1.34), no routing. ~15 MB world.pmtiles fallback.

**Creator Packs and licensing.** v1.34 creator-packs.json: three video ZIM packs (Project NOMAD 178 MB, Crosstalk 2,899 MB, Modern Rogue 5,177 MB) under `nomad-creator-pack-1.0`, a **DRAFT** licence ("not reviewed by an attorney"): household use only, no redistribution, "A fork may not distribute or serve Creator Packs". Enforcement: creator_pack_service.ts fetches `${CREATOR_PACKS_WORKER_BASE||'https://nomad-packs-worker.chris-556.workers.dev'}/packs/{id}_{version}.zim` with a bearer CREATOR_PACKS_APP_KEY baked only into official CI images (PR #1106 describes a private Cloudflare R2 bucket); source builds have no key and hide the feature. (One gap-fill researcher found no mention on the website/docs — the code and PR #1106 are the better-supported source.) NOMAD hosts no other content. Grey areas: roughly half the Survival tier by bytes is Kiwix crawls of YouTube channels with undocumented permission; maps are ODbL; no copyright issue has been raised in the repo or on HN.

**ARM64 status (gap-fill, verified 3 Sep 2026).** PR #419 (multi-arch CI, diff is 3 workflow YAMLs + README, +172/−18) open since 20 Mar 2026, labelled Roadmap Item; maintainer 16 Jul 2026: "We WILL get there… when we're ready". Upstream is already arm64-ready in source: Dockerfile has `ARG TARGETARCH` with a pinned arm64 SHA for go-pmtiles 1.30.2; sidecars are plain alpine; app code maps aarch64→arm64. Registry checks: every pinned workload image publishes linux/arm64 (kiwix-serve 3.8.1, ollama 0.24.0, qdrant v1.16, kolibri 0.19.4, cyberchef 10.24.0, flatnotes v5.5.4, dozzle v10.0, mysql 8.0, redis 7-alpine, s-pdf 2.13.1, calibre-web 0.6.26-ls386, jellyfin 10.11.11, filebrowser v2, it-tools, meshtastic-web 2.7.1, meshcore-web v1.45.0, homebox 0.26.2, vaultwarden 1.36.0, nomad-sysbench) **except** excalidraw/excalidraw:sha-4bfc5bb (2021, amd64-only; `:latest` is multi-arch). Maintainer in #1156 (Jul 2026): "A Raspberry Pi 5 running Ubuntu 26.04 arm64 currently runs Project NOMAD fine". suranyami/project-nomad publishes multi-arch images a user confirmed "fully usable on a Raspberry Pi 5" but is frozen at March 2026 (older Kolibri 0.12.8, no pmtiles step); csepanyij/project-nomad-on-arm has zero unique commits. Net: a Pi 5 build = `docker buildx build --platform linux/arm64` of upstream + one Excalidraw tag bump; nobody has published a native arm64 build of the current tree.

**Fork mechanics (gap-fill).** Manifest URLs (SPEC_URLS in collection_manifest_service.ts, duplicate in zim_service.ts), image repo `ghcr.io/crosstalk-solutions/project-nomad` and releases feed (auto_update_service.ts, system_service.ts, system_update_service.ts), maps repo (map_service.ts, kiwix_catalog_service.ts), bootstrap ZIM URL (docker_service.ts), installer/updater raw URLs (install_nomad.sh, run_updater_fixes.sh) and the sidecar's `sed` anchored on the upstream image name (update-watcher.sh) are all hard-coded — no env var or Setting. Env schema has only INTERNET_STATUS_TEST_URL, NOMAD_STORAGE_PATH, NOMAD_API_URL, CREATOR_PACKS_*. About ten literals in nine files — mechanical enough to apply as a patch to each upstream tag in CI. A fork that leaves the compose image line at upstream is overwritten by the next update; one that changes only the image line loses tag pinning. Brand string is a Vite build-time constant; footer renders "Project NOMAD™ Command Center". Manifests are simple JSON validated by VineJS (curated_collections.ts). Regional localisation proposals (#1262 French, #1221 Bengali) were closed "not planned" 25–26 Aug 2026; upstream's answer is #1272, a Bergamot translation proxy, amd64-only.

No. 99912179 "PROJECT NOMAD", standard-character, Class 9 ("Downloadable software, capable of functioning offline, for access to educational content, reference materials, and AI tools"), filed 29 Jun 2026, first use 12 Mar 2026, status LIVE / Awaiting Examination; no UK IPO or EUIPO filing located. **Where the US-centricity shows.** maps.json US-only (TIGER/Line polygons); medicine tier CDC/MedlinePlus/openFDA/NCCIH/FAS; survival tier Ready.gov/FEMA, Gutenberg military science, Canadian/US YouTube preppers; UI and wikipedia.json English-only; USD prices; generic ham SE with no Ofcom material; Legal & Civic still TODO and framed around "constitutional documents". Counter-examples: nhs.uk_en_medicines in the Essential tier; Protomaps extraction covers the UK. No UK/European fork exists — whitespring/project-nomad-maps-europe has German/Austrian/Swiss/Croatian/Danish PMTiles, no UK; the only UK write-up (readthemanual.co.uk) makes no UK adaptations.

# llm_recommendation

## What is realistic

**Model tier.** Only 1–4B-effective parameters at Q4 are usable on Pi 5 / N100 hardware, and only when answers are grounded by retrieval. Measured: Pi 5 8GB — Gemma 4 E2B Q4_K_M (1.2 GB, Apache-2.0 + prohibited-use policy, 128K ctx) 8–12 tok/s on Ollama, 7 tok/s gen / 20 tok/s prefill on a tuned llama.cpp build (GGML_ARM_DOTPROD, KV cache q4_0, performance governor; a stock binary managed 1.5 tok/s); Gemma 3 1B ~10 tok/s; Llama 3.2 3B 4.5–4.9 tok/s (identical on 8 GB and 16 GB); Gemma 4 E4B swaps on 8 GB (3–5 tok/s). Pi 5 16GB — Qwen3-30B-A3B-Instruct 2.7-bpw MoE ~8 tok/s in ~10 GB (`-c 4096`), the most capable thing that fits. N100/N150 — Llama 3.2 3B 8–9 tok/s, 8B 3.6–3.9, deepseek-r1:1.5b 17–18; run CPU-only (iGPU via SYCL/Vulkan is "often negative"). Alternatives with clean licences: Qwen3.5 2B/4B (Apache-2.0, disable thinking), Phi-4-mini 3.8B (MIT); Llama 3.2 is under the Llama Community Licence; MedGemma 1.5 4B is gated HAI-DEF and explicitly "not a medical device". Quant: Q4_K_M everywhere.

**Runtime.** Build on llama.cpp (10–20% faster than Ollama; KleidiAI/dotprod flags matter). Test Google's LiteRT-LM for Gemma 4: 99 tok/s prefill / 9 tok/s decode in 1.4 GB on Pi 5 versus 24/4 in llama.cpp — prefill speed is the RAG bottleneck (a 2–3k-token retrieved context takes 1.5–5 min to first token at 10–25 tok/s prefill). Keep retrieved context ≤1,000–1,500 tokens on a Pi. Skip ExecuTorch and the Hailo AI HAT+ 2. Active cooler and 27 W PSU are mandatory; sealed-enclosure throttling is unmeasured.

**NOMAD's stack on a Pi.** NOMAD uses Ollama + Qdrant with nomic-embed-text; embedding whole ZIMs is impractical (hours per 2 GB ZIM; RFC #883: 10 GB ZIM → 1–100 GB Qdrant). For a UK build use lexical retrieval first: kiwix-serve already exposes `/search?pattern=…&books.name=<zim>&format=xml&pageLength=N` (Xapian snippets, ≤140 results) and python-libzim 3.12 has aarch64 wheels with `Searcher/Query` (check `Archive.has_fulltext_index` per ZIM). Existing patterns: openzim-mcp (MIT, v3.2.5 Sep 2026), llm-tools-kiwix (caps at 3 articles, returns paths as citations), survive-ai (SQLite FTS5 BM25 + optional EmbeddingGemma re-rank fused by RRF, QueryRouter that declines off-corpus, AnswerGuard that blocks output contradicting the retrieved passage, paragraph-level citations). Pocket RAG (Jan 2026) hit 94.5–97% on first-aid MCQs with Qwen3-0.6B using keyword pre-filter + small dense re-ranker in 2 GB. Keep NOMAD's Qdrant path for user-uploaded PDFs only.

**Why RAG over UK sources, not fine-tuning.** UKHSA's PubHealthBench (8,000+ MCQs from 687 NHS/GOV.UK documents): unaided, Gemma-3-4B scores 72% MCQ but 37% free-form; Llama-3.1-8B 80% / 19%; Phi-4-4B 82% / 19%; Gemma-3-1B 48% / 18%. With hybrid dense+sparse retrieval over the official text (k=3–5), Gemma-3-4B reaches 95.6%, Phi-4-4B 97.1%, Llama-3.1-8B 97.9%, no retraining — and the corpus can be updated in place, which fine-tuned weights cannot. EmbeddingGemma 0.3B was the weakest embedder tested (nDCG@10 0.27 dense / 0.50 hybrid), so lexical-first with a small dense re-ranker is the right shape. LoRA is only for tone/format (British spelling, 999/111/105 pathways, UK drug names) and even that belongs in a nomad.md system prompt.

## Safety mitigations to plan (evidence-driven)

1. **Retrieval-first, cite-or-refuse.** Answer only from retrieved passages; show the verbatim source passage with ZIM name, article path and "as at" date; QueryRouter declines outside the corpus. A 23-model offline ICU simulation (Feb 2026) found ~40% accepted a contraindicated drug and only 8.7% grounded refusals in context — the model must not be the source of truth.
2. **Answer-vs-source check** (AnswerGuard pattern): block or flag outputs that contradict the cited passage; cap history at ~4 turns and questions at ~400 chars.
3. **Health pathway is not a chatbot.** Route symptom/medicine/first-aid questions to the verbatim NHS page (Kiwix "fixed content", MHRA low-functionality category B/C) rather than generating. MHRA's 2025/26 functionality test classes any AI-generated personalised output as "high functionality", so an LLM that lists likely conditions, ranks them, flags red flags or "provides treatment recommendations, e.g. first aid treatment" for a lay user is likely a medical device (Class I self-cert, Class IIa with an Approved Body if it gives an "indicative diagnosis"); "for information only" disclaimers are "not acceptable"; intended purpose is read from landing page, app-store text, marketing and testimonials. Signposting ("call 111/999, see your GP") and unranked reference information are unlikely to be devices. Marketing must never claim a medical purpose.
4. **NHS OGL attribution rules shape the UI.** Verbatim NHS text: "Information from the NHS website … as at DDMMYY" + OGL line. Any LLM paraphrase is "adapted" content: it must carry "Contains public sector information licensed under the Open Government Licence v3.0", must NOT be attributed to the NHS, and "may invalidate its formal clinical approval". So: model text and NHS text visually separated, and no "NHS-grounded AI" claims (3.11 no-endorsement clause).
5. **Non-UK sources labelled as such** (MedlinePlus/CDC/WikEM are US-framed; drug names differ: paracetamol vs acetaminophen). Prefer nhs.uk medicines + WikiMed; dm+d (OGL) as the product/ingredient backbone; there is no OGL SmPC/BNF equivalent, so no dosing engine.
6. **Standing warnings in framing, not just banners:** "Local AI can be wrong; the downloaded references are the source of truth" (NOMAD's own website FAQ wording); no berry/fungus identification from images (The Register's "Russian roulette" critique, and zero-knowledge for UK species).
7. **Refresh discipline:** re-pull models every 6 months and content annually at minimum (localaimaster guidance); show the model card, quant and date in the UI.
8. **Evaluation before shipping:** build a small UK free-form test set (outage, first aid, medicines, foraging law) with human review — PubHealthBench shows MCQ scores overstate free-form reliability by 40–60 points; no project has evaluated Kiwix-grounded answers from 2–4B models on open-ended questions.
9. **Thermal/power budget:** LLM generation is the only workload that pushes a Pi to 10–15 W; disable it automatically below a battery threshold and warn that a query costs minutes of battery.

**Default recommendation:** ship the assistant off by default in the Pi/battery tier, on by default on x86/mains; Gemma 4 E2B (or Qwen3.5-2B) via llama.cpp/LiteRT-LM with kiwix-serve lexical retrieval; NOMAD's Ollama+Qdrant assistant retained for the x86 tier with a UK nomad.md, a health-query router that returns NHS pages verbatim, and citations rendered as links into Kiwix.


# audience

## Who the UK users are

- **r/UKPreppers regulars** — the core early adopters. They already run Kiwix ("Just start with Kiwix"), OsmAnd/CoMaps/OS Maps offline, e-readers with PDFs, Jellyfin instead of Plex, and at least one asked for "a small llm to query all this offline data" (Jul 2026). They reject US-style bug-out/crossbow fantasies ("I live in rural Devon"; "stop this romantic Hollywood fantasy of Bugging Out. Just stay put"). Facebook groups (UK Preppers and Survivalists 22,700; UK Preppers Club 6,000) are larger but closed to keep politics out. Academic profile: predominantly middle-class mothers; one in five Britons prepped during Brexit.
- **Households nudged by government** — 2026 UK Public Survey (10,000+ adults): 13% feel prepared; 25% could cope ≤1 day in a combined outage; 23% own an FM radio; only 14% have visited Prepare; 84% want government guidance; 71% willing to volunteer locally. The Aug 2026 "store water and tinned food" announcement and a larger late-2026 campaign will widen this group; r/UKPreppers reaction: "About time" / "Not nearly forthright enough".
- **Community emergency-planning volunteers** — parish councils (Horam plan, Mar 2026), Ready Scotland groups (skills/asset registers, RAYNET contacts, notice boards), Welsh LRFs post-Storm Darragh, street WhatsApp groups left over from Covid ("they just call it community emergency planning"). They need editable, printable plans, not a library.
- **Rural notspot residents** — Highlands (16% no broadband; 11% of Scotland no 4G), Somerset/Devon/Northumberland villages, Welsh villages cut off 6 weeks, NI after Éowyn ("without power and/or water for weeks"). Life-safety stakes: 999 via Digital Voice fails after ~1 h battery; PSTN off by Jan 2027.
- **Outdoor / DofE / Mountain Rescue culture** — map-and-compass first, phone sealed for emergencies, OS Locate for grid refs; MREW says call-outs rise because walkers lack "the analogue back-up". A server must be pitched as complementing paper and skills.
- **Comms hobbyists** — UK Meshtastic/MeshCore (UKSN adopted LoRa; Mesh Hub UK), RAYNET (~1,800 members), PMR446/CB users, new Foundation licensees (+30% candidates 2024). Insiders warn Meshtastic is "very unreliable in the UK", MeshCore better, PMR446/CB more practical for the public.
- **Van-life / narrowboat** — connectivity and offline POIs only; no evidence of wider demand.

## Scenarios they actually plan for
2–3 day gas or electric cuts (a farmer's fence post cut gas to 4,500 homes for 4 days in Jan 2026), 5–7 days stuck at home, storms (Arwen: 4,000 customers >1 week, last restored day 13; Éowyn: up to 10 days, Three Ireland 34% of sites off-air), cyber attacks on CNI (42% think likely), food/fuel supply hiccups, cashless failures (Aldi card machines, Vodafone/Three outages), job loss. National Risk Register planning assumptions to mirror: national grid failure up to 7 days for restoration, critical services months; regional power "several weeks" in remote areas; telecoms cyber attack 72 h to weeks; "simultaneous loss of all fixed and mobile communication" is a listed risk; the Apr 2025 Iberian blackout is their reference case study. Nuclear war and civil unrest are discussed but treated as unpreparable or fringe ("prep with a few Kalms").

## The information gaps they name
"All the info I see online is American" (bleach dosing — UK bleach is thickened; use NaDCC tablets); official advice is "just a website … If the power/web is taken out people won't have access to this information. Oops"; Prepare itself says it "will not be updated with live information during an emergency" and tells people to write down radio frequencies on paper; confusion over what still works (mast batteries, Digital Voice, FM vs DAB, Radio 4 LW gone in 2026, grid-tied solar shutting off without an islanding switch). Books they cite: Seymour's Complete Book of Self Sufficiency, Mabey's Food for Free, SAS Survival Guide, Dartnell's The Knowledge, Where There Is No Doctor/Dentist — all copyrighted; the open equivalents largely do not exist (see catalogue).

## Framing sensitivities
- **"Tuesday not Doomsday."** Say resilience, emergency planning, outage kit; avoid "prepper", "Command Center" militaria, Faraday-bag/EMP marketing (HN: "This is larping as a prepper"). Real stigma: "the first rule of prepping is not to talk about prepping"; bulk buying is framed as cost saving.
- **Sceptics of gadgets:** "knowledge needs to be in your head, not on a usb stick"; books are "EMP resistant, un-hackable"; "by the time you have got that thing working, someone will have stabbed you" (PistonHeads). Counter with cheap, robust, battery/solar-runnable, works from any phone, prints the household plan.
- **Weapons law:** knives (CJA 1988 s139, ≤3" non-locking exemption), crossbows, pepper spray illegal; Scotland/NI differ. Include accurate UK law summaries; exclude armed-defence content. Community mocks "tacticool".
- **Terrorism Act 2000 s58:** possessing information "likely to be useful to a person committing or preparing an act of terrorism" (max 15 years, reasonable-excuse defence) — bundling US Army field manuals as US boxes do is a real optics/legal question for a UK distributor.
- **Medicines:** NHS prescription rules make stockpiling hard ("skipping the odd dose"); do not encourage hoarding or antibiotic self-supply; point to 111, Pharmacy First, PSR; cover disability, flats without outside taps, babies, pets (gaps ukprepperhub identifies in the government kit).
- **Politics/sectarian framing** gets pushback; keep it out entirely.
- **Language:** Welsh where licences allow; Gaelic not investigated; no box today offers either.


# design_questions

- 1. What is the software base? (A) Overlay fork of Project NOMAD: patch the ~10 hard-coded literals in 9 files, rebuild amd64 + arm64 via buildx (bump excalidraw to a multi-arch tag), publish own images and own collections repo — gets Command Center, RAG, MapLibre maps, Supply Depot for near-zero engineering, but inherits x86-first/Docker, no hotspot, no auth, 4 GB minimum and a per-release rebase. (B) Kiwix Hotspot / offspot image (GPL-3.0, Pi-native, captive portal, 4–9 W) carrying UK ZIMs + PMTiles — no LLM/RAG UI. (C) Internet-in-a-Box 8.3. (D) Own thin stack (nginx + kiwix-serve + PMTiles + llama.cpp + small UI). Recommended default: (A) for v1 with the content layer (UK manifest JSON, ZIMs, PMTiles, plan templates) built platform-neutral so the same artefacts can ship as an offspot bundle (B) for the battery tier; open an upstream PR adding NOMAD_COLLECTIONS_BASE_URL / NOMAD_IMAGE_REPO / NOMAD_RELEASES_URL so the overlay can become compose-only.
- 2. What is it called and how does it relate to upstream? (A) 'NOMAD UK' — uses the dominant element of USPTO application 99912179 (Class 9, live, awaiting examination) for identical goods; weak enforceability in the UK but invites a rename and confuses users because the unmodified footer says 'Project NOMAD™ Command Center'. (B) New name + 'an unofficial UK build of Project NOMAD' attribution (Apache-2.0 §6 customary use), own ghcr namespace and domain. (C) Email Crosstalk for written permission / 'Powered by Project NOMAD' co-branding before choosing. Recommended default: (B) immediately, plus (C) in parallel; never put NOMAD in the product name, image namespace or domain, and ship creator-packs.json with packs: [] and no CREATOR_PACKS_APP_KEY (draft licence: 'A fork may not distribute or serve Creator Packs').
- 3. Distribute a disk image only, or sell a kit? (A) Image + tested parts list only — a stand-alone image is not a PSTI 'product', so no PSTI duties fall on you. (B) Sell pre-flashed kits under your brand — you become the PSTI 'manufacturer' (Act ss.4–7): universal defaults like Calibre-Web admin/admin123 and File Browser admin/nomad are banned (SI 2023/1007 Sch.1 para 1 covers pre-installed software), you must publish a vulnerability-disclosure contact and a security-update end date, and each unit needs a statement of compliance; penalties up to £10m/4% turnover; the 'desktop computer' exception is undefined and framed as 'conventional IT products', so do not rely on it. (C) Partner with a UK reseller (e.g. The Pi Hut) as manufacturer of record. Recommended default: (A) for v1; move to (B) only after a first-boot wizard generates per-unit secrets for every Supply Depot app (the installer already randomises MySQL passwords) and the Command Center is behind at least Caddy basic auth; publish the security contact and support window anyway.
- 4. What is the LLM's scope and posture? (A) No LLM — Kiwix search only; sidesteps MHRA, hallucination and power cost. (B) 'Search assistant': lexical retrieval over the UK corpus (kiwix-serve /search or python-libzim), verbatim cited passages with 'as at' dates, refuses off-corpus, and a query router that answers symptom/medicine/first-aid questions by returning the NHS page verbatim (MHRA low-functionality category B/C) rather than generating; marketing never claims a medical purpose. (C) Full NOMAD-style RAG chat including personalised health answers — MHRA: an LLM 'adapted or directed toward' a medical purpose is likely SaMD (Class I self-cert, Class IIa with Approved Body for lay 'indicative diagnosis'); disclaimers 'not acceptable'; NHS OGL: paraphrase is 'adapted' content that cannot cite the NHS. Recommended default: (B). Keep NOMAD's Ollama assistant on the x86 tier with a UK nomad.md (British spelling, 999/111/105/PSR, UK drug names), an AnswerGuard-style contradiction check, citations as links into Kiwix, and the assistant off by default on the Pi/battery tier.
- 5. Which basemap? (A) Protomaps UK+Ireland PMTiles extract (`pmtiles extract --bbox=-11,49.5,2,61`, z0–15, ODbL, est. 2–4 GB) — covers Northern Ireland and works unchanged in NOMAD's MapLibre viewer and sprites. (B) OS Open Zoomstack MBTiles→PMTiles (OGL v3, 2.85 GB) — GB only, needs the OS Zoomstack style, no NI. (C) Both, plus overlays: OS Terrain 50 contours (1.07 GB MBTiles), CRoW access land, EA flood zones, council PRoW, OSNI 1:10k raster for NI. Recommended default: (A) as the v1 default map in the UK maps manifest, hosted on Cloudflare R2 with a custom domain (zero egress; ~$0.30/month for 30 GB) rather than GitHub LFS ($0.0875/GiB bandwidth, 2 GB/file cap); (B) and the overlays as optional downloads; also list Organic Maps UK .mwm (2.28 GB) for phone sideload.
- 6. Where is the licence floor? (A) Strictly OGL v3 / ODbL / CC0 / CC-BY / CC-BY-SA / public domain — commercial-clean, can be sold or bundled with paid hardware. (B) (A) plus an opt-in, clearly labelled non-commercial pack: WHO EML 2025 (CC BY-NC-SA), PFAF (CC BY-NC-SA, £40), iFixit (3.3 GB), LibreTexts, HSC/PHA Northern Ireland content. (C) Also include grey material: Kiwix crawls of Canadian/Urban Prepper, S2 Underground, trueprepper, survivorlibrary, and US military field manuals. Recommended default: (B) with the NC pack flagged in the manifest and UI; exclude (C) — undocumented permission, Terrorism Act s58 optics for military manuals — and ask Hesperian in writing for Where There Is No Doctor rather than mirroring it.
- 7. How are NHS and gov.uk ZIMs produced and refreshed? (A) Rely on the Kiwix library: nhs.uk_en_medicines is quarterly but its June 2026 build failed (`--lang eng`), the Prepare ZIM was built 3 Aug 2026 (147.6 MB) yet remains unpublished with the request parked 'Upstream', and the 4.12 GB conditions ZIM was deleted over unplayable Brightcove video. (B) Self-build monthly with zimit 3.1.3 (Browsertrix 1.14.1 + warc2zim 2.3.1) or from the NHS Website Content API (free key + OCA, 1,200 req/min, ~4,000 pages in ~4 minutes, /manifest/pages for deltas), exclude Brightcove/assets video via --scopeExcludeRx, stamp every ZIM 'Information from the NHS website as at DDMMYY' (the OGL T&C route that tolerates a dated snapshot instead of a 7-day refresh), host on Cloudflare R2 or GitHub Releases (<2 GiB/file). (C) Both: self-build as the manifest URL of record and file zim-requests so Kiwix picks them up. Recommended default: (C); write to the NHS website team (T&C 14.4) to confirm the dated-snapshot route for API-sourced content, scope legislation.gov.uk to named Acts via per-Act data.htm (Crawl-delay 5, 1,500 req/5 min), and prefer the GOV.UK Content API (10 req/s, no onboarding) for gov.uk pages.
- 8. Is a community/mesh layer in v1? (A) None — library only. (B) Content-only: Household Emergency Plan (Prepare DOCX) and Ready Scotland community templates (skills/asset register, rest centre, RAYNET, alternative comms) as FlatNotes/Markdown with a printable view, plus a 'UK links & numbers' page (105, DNO lookup, Priority Services Register, 111, EA Floodline 0345 988 1188, Emergency Alerts) and a 'what still works in an outage' explainer. (C) A structured, editable community-plan app with USB/peer sync. (D) A Meshtastic/MeshCore bulletin publisher on EU868 under IR2030 (≤200-byte cached Met Office/EA warnings, rest-centre notices) — file sharing over LoRa is a dead end. Recommended default: (B) in v1 (no code, high differentiation); (C) and (D) on the roadmap after a Pi/battery tier exists and Ofcom IR2030 duty-cycle limits for periodic broadcasts are confirmed.

# risks

- Trademark: 'PROJECT NOMAD' USPTO application 99912179 is live (Class 9, identical goods); Apache-2.0 §6 grants no name rights; any 'NOMAD UK' product name, ghcr namespace or domain invites a rename request and user confusion.
- Creator-pack licence (draft) forbids forks from distributing or serving packs; a fork that carries upstream's baked-in CREATOR_PACKS_APP_KEY or points at the upstream Worker breaches it — ship an empty packs manifest and no key.
- Fork drift: manifest URLs, image repo, releases feed, maps repo and the updater's sed pattern are hard-coded to Crosstalk's GitHub/ghcr; an unpatched fork is silently overwritten by upstream's auto-updater, and every upstream release (roughly monthly) needs a rebase of ~10 literals.
- Upstream will not carry regional variants (French/Bengali proposals closed 'not planned' Aug 2026; catalogue browser hard-codes lang eng); the UK build is a permanent downstream fork with no upstream help.
- PSTI Act 2022 applies the moment a kit is sold under your brand: universal default passwords in pre-installed apps (admin/admin123, admin/nomad) are banned, and a published vulnerability contact, support end-date and per-unit statement of compliance are required; penalties up to £10m or 4% of turnover.
- MHRA: an LLM that answers symptom/medicine questions with ranked conditions or treatment steps is likely software-as-a-medical-device (Class I self-cert, Class IIa for lay 'indicative diagnosis'); 'for information only' disclaimers are expressly not accepted; a 2026 pre-market SI may up-classify decision-support software.
- NHS OGL terms: any LLM paraphrase is 'adapted' content that must not cite the NHS and 'may invalidate its formal clinical approval'; offline copies must carry a dated 'as at' attribution; no-endorsement clause bars 'NHS-grounded AI' claims.
- Hallucination: 4B-class models score 19–37% on free-form UK public-health answers unaided; a 23-model offline ICU study saw ~40% accept a contraindicated drug; grounded retrieval with citations and refusal is a hard requirement, not a nicety.
- Terrorism Act 2000 s58 exposure/optics if the UK bundle mirrors US-style military field manuals; the UK community itself does not want armed-defence content.
- The 'UK' health corpus is England-heavy: NHS inform (Scotland) forbids scraping and derivatives, NHS 111 Wales reuse is gated by an unpublished policy (Welsh translations unclear), HSC/PHA Northern Ireland is non-commercial only; only nhs.uk, nidirect and Department of Health NI are OGL.
- Kiwix library publication is not guaranteed: the Prepare ZIM built successfully but is unpublished, the NHS medicines rebuild failed in June 2026, the NHS conditions ZIM was deleted; Zimfarm's minimum cadence is quarterly, so self-hosting is unavoidable for freshness.
- Content staleness: upstream manifests live on the main branch (catalogue changes ship without a release); Kiwix ZIM cadence is uneven (mdwiki 17 months); NHS content refresh rules make undated stale copies a licence breach as well as a safety problem.
- Hardware price and stock volatility: Pi 5 8GB rose to £168 (Feb 2026 LPDDR4 shortage), 1 TB NVMe £117.99, 4 TB £329.99; Pimoroni out of stock; Pi Zero 2 W sold out — published BOMs will drift.
- Pi 5 performance is unproven as a whole: no combined benchmark of hotspot + kiwix-serve + PMTiles + LLM under multi-client load; RAG prefill can mean 1–5 minutes to first token; sealed-enclosure throttling unmeasured; no arm64 build of the current NOMAD tree has been published by anyone.
- Community reception: UK stigma around 'prepping', HN/PistonHeads critiques ('larping', 'knowledge needs to be in your head', 'doesn't look very robust'); military/apocalypse framing or a mains-only 65 W box will be rejected by the core audience.
- Captive-portal and hotspot UX is unreliable on modern Android/iOS and NOMAD has no hotspot mode at all; without a printed SSID/password/fallback-URL card and a travel-router or offspot path, non-technical users will fail to connect.
- ODbL share-alike: combining OSM with OS/OSNI data into a derived database inherits ODbL; keep OGL and ODbL layers as separate files with separate attribution.
- Genuine content gaps that cannot be licensed: UK tide tables (UKHO paid), BNF/SmPC dosing (no OGL equivalent; MHRA API returned 503), UK foraging/fungi field guides and sowing calendars (all proprietary) — these must be authored or omitted, and users will notice.
- Hosting egress: GitHub LFS bills $0.0875/GiB beyond 10 GiB and caps files at 2 GB on Free/Pro; a popular multi-GB ZIM on LFS can cost tens of dollars a month — use R2 (zero egress) or GitHub Releases.
